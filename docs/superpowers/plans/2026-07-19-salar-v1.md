# SALAR v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Produce a tested FastAPI backend, shared React/PWA client, Tauri Windows desktop app, deployable website directory, professional icon, and NSIS installer for SALAR.

**Architecture:** One public FastAPI service owns authentication, data, AI coordination, retrieval, and device command routing. One React client targets browsers, mobile PWA, and Tauri; the Windows shell adds a permission-gated Rust automation bridge and device WebSocket.

**Tech Stack:** Python 3.9+, FastAPI, SQLAlchemy, SQLite, ChromaDB, Ollama HTTP API, React 19, TypeScript, Vite, Vitest, Tauri 2, Rust, Docker, Caddy.
